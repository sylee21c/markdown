# Markdown 사용법

Markdown은 간단한 기호를 사용하여 문서의 구조와 서식을 표현하는 문법이다. `.md` 확장자를 사용하며 README, 개발 문서, 게시글 등에 활용된다.

## 1. 제목

문장 앞에 `#`을 붙여 제목을 만든다. `#`의 개수에 따라 제목 단계가 달라진다.

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
```

## 2. 글자 강조

```markdown
**굵은 글씨**
*기울임 글씨*
~~취소선~~
`인라인 코드`
```

표시 결과:

**굵은 글씨**<br>
*기울임 글씨*<br>
~~취소선~~<br>
`인라인 코드`

## 3. 목록

### 순서가 없는 목록

```markdown
- 항목 1
- 항목 2
  - 하위 항목
```

### 순서가 있는 목록

```markdown
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목
```

## 4. 체크박스

```markdown
- [x] 완료한 항목
- [ ] 완료하지 않은 항목
```

표시 결과:

- [x] 완료한 항목
- [ ] 완료하지 않은 항목

## 5. 링크

링크 이름을 대괄호에 쓰고 주소를 소괄호에 작성한다.

```markdown
[GitHub](https://github.com/)
```

표시 결과: [GitHub](https://github.com/)

## 6. 이미지

링크 문법 앞에 느낌표를 붙인다.

```markdown
![대체 문구](이미지 주소)
```

## 7. 인용문

문장 앞에 `>`를 붙인다.

```markdown
> 인용문입니다.
```

표시 결과:

> 인용문입니다.

## 8. 코드 블록

코드의 위와 아래를 백틱 세 개로 감싼다. 시작 부분에 언어 이름을 쓰면 문법 강조가 적용된다.

````markdown
```python
print("Hello, Markdown")
```
````

표시 결과:

```python
print("Hello, Markdown")
```

## 9. 표

세로선과 하이픈을 사용하여 표를 만든다.

```markdown
| 항목 | 설명 |
|---|---|
| 제목 | 문서의 제목을 표시한다. |
| 목록 | 여러 항목을 정리한다. |
```

표시 결과:

| 항목 | 설명 |
|---|---|
| 제목 | 문서의 제목을 표시한다. |
| 목록 | 여러 항목을 정리한다. |

## 10. 구분선

하이픈을 세 개 이상 작성한다.

```markdown
---
```

표시 결과:

---

## 11. 줄바꿈

문단 사이에 빈 줄을 넣으면 새로운 문단이 된다. 같은 문단 안에서 줄을 바꾸려면 문장 끝에 공백 두 칸을 입력하거나 `<br>`을 사용한다.

```markdown
첫 번째 줄<br>
두 번째 줄
```

## 12. 특수문자 표시

Markdown 기호를 서식으로 해석하지 않고 그대로 표시하려면 기호 앞에 역슬래시를 붙인다.

```markdown
\*별표를 그대로 표시하기\*
```
